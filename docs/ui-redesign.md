# BEAT GREEDY v1.1 — 视觉与体验改版规格

> 2026-10-20 · 目标：从“暗色终端”改成“新中式小卖部 / 手账贴纸 / 街机反馈”，中文优先，增加人物评论与声音，但不改变算法玩法。

---

## 1. 改版目标

用户原话里的约束拆成五条可执行要求：

1. **降低怪诞浓度**：Boss 立绘已经够怪，界面回到温暖、热闹、有人情味的日常场景。
2. **更多“小细节”**：Boss 会评价、会风凉话；结算有“老板点评”和“本局人设”。
3. **参考热门小游戏**：羊了个羊的密集可点、合成大奶蛙的软萌大玩区、狙击外星人的粗描边和大按钮。
4. **参考高级中式视觉**：黑神话悟空的印章、留白、书法标题、做旧纸感，但整体必须明亮、亲和。
5. **中文语境**：中文是主语言，英文只做小号装饰标签；不堆 emoji，不用规整方框。

一句话方向：

> **欢迎光临贪心小卖部。老板牛来只拿眼前最划算的；你可以把整间店看一遍。**

## 2. 研究结论（2026-10-20）

### 2.1 热门小游戏

| 参考 | 观察 | 采用 |
|---|---|---|
| 羊了个羊 | 高饱和绿色、卡通角色、木牌/货架、超大按钮、信息密度高但不乱 | 大按钮、货架感、密集但分层的贴纸信息 |
| 合成大奶蛙 | 奶油/米色底、软糯角色、虚线、中央大玩区、HUD 极轻 | 米纸底、虚线空状态、减少金属/终端感 |
| 狙击外星人 | 高饱和卡通城、圆形取景器、胶囊按钮、夸张结算卡 | 圆形计时器、胶囊 CTA、有仪式感的结算 |

### 2.2 黑神话悟空

采用其“高级中式”的构成方法，不采用其暗黑题材：

- 朱砂印章、落款、留白；
- 书法/倾斜黑体做标题，正文克制；
- 纸张、墨色、旧金色；
- 结算像一张“票据/告示”，而不是一个网页卡片。

### 2.3 中式包装与网络语感

- 参考老式零食包装、副食店价签、搪瓷、铁皮玩具、小卖部货架。
- 文案方向：短句、口语、轻微阴阳怪气，但不侮辱玩家。
- 关键词：拿捏、包的、硬塞、破防、不讲武德、差价、进货价、格局打开、精准踩雷、含泪赚了。
- 每屏最多 2–3 个梗，避免“梗浓度过高像营销号”。

> 小红书站内搜索在当前环境无法直接抓取（需登录、结果未索引），因此网络梗部分以公开可检索的中文语料和手工筛选为准，不直接搬运具体博主文案。

### 2.4 声音

不下载、不采样任何影视/短视频音频。用 Web Audio 现场合成：

- D 小调五声音阶（D F G A C）的木琴/拨弦循环；
- 木鱼/木块节拍、轻低音；
- 点击、拿取、退回、超重、交卷、胜负、满配音效；
- 首次交互后解锁 AudioContext；默认开启，可一键静音并本地记住。

## 3. 视觉系统

### 3.1 色彩

| Token | 色值 | 用途 |
|---|---|---|
| `rice` | `#f4ead7` | 页面米纸底 |
| `rice-deep` | `#e9d9bd` | 纸袋、分隔、底纹 |
| `cream` | `#fff9ec` | 卡片、票据 |
| `ink` | `#2a251e` | 主文字、描边 |
| `ink-soft` | `#6d604e` | 次级文字 |
| `vermilion` | `#d6402c` | 主 CTA、印章、警示 |
| `vermilion-deep` | `#a52e1f` | 按压/阴影 |
| `mustard` | `#e3a33c` | 价签、胶带、辅助高亮 |
| `jade` | `#3e7757` | 已选、正确、胜利辅助 |
| `line` | `#d8c8ac` | 纸上的分隔线 |
| `night` | `#211e19` | Boss 照片底、少量对比块 |

避免：大面积纯黑、荧光酸性色、紫色渐变、玻璃拟态。

### 3.2 字体

- 展示字：**BG Shop Display**。基于 Smiley Sans（得意黑）子集化并重命名（OFL-1.1 保留字体名要求），只保留项目用字。用于大标题、数字、按钮。
- 正文：系统中文字体栈（PingFang SC / Hiragino Sans GB / Microsoft YaHei）。
- 小标签：系统 sans，大写英文只用 9–10px 的字距拉开做“票据注脚”。
- 数字使用 `font-variant-numeric: tabular-nums`。

### 3.3 材质与形状

- 米纸底色 + 极淡账本横线 + 细颗粒噪点。
- 卡片：奶油底、2px 墨线、12–18px 圆角、硬偏移阴影；随机 ±0.6° 微旋转。
- 胶带：半透明芥末色长条，压在卡片角上。
- 印章：朱砂双线框，旋转 -8° 左右，文字用展示字。
- 票据：顶部平、底部锯齿边；虚线撕口；打孔圆点。
- 按钮：胶囊形，朱砂底奶油字，底部 5px 实心阴影，按下下沉。
- 空状态：虚线框 + 手写感提示，不用灰色死板占位。
- emoji：只保留 Boss 数据里的兜底字段；物品、按钮、状态一律用自绘 SVG 或文字。

### 3.4 动效

- 入场：卡片错峰上浮 8–14px；
- 拿取：卡片上浮 + 轻转 + “已装”章；
- 超重：横向抖动 + 朱砂提示条；
- 计时告急：数字变朱砂、圆形进度闪动；
- 交卷：覆盖 0.8s 的“老板正在数货……”；
- 结算：票据展开、评级盖章、满配纸屑。
- 全部尊重 `prefers-reduced-motion`。

## 4. 页面与组件

### 4.1 开始页

- 顶部：朱砂“贪”印章 + “贪心小卖部 / BEAT GREEDY”，右侧静音开关与本场最高分。
- 左侧：
  - 条纹雨棚 + 木牌店招“贪心小卖部”；
  - 大标题“别只拿眼前那件。”；
  - 副文案解释老板只拿眼前最划算，你能看全货架；
  - 三个事实标签：8 件货 / 30 秒 / 0 登录；
  - 难度选择做成三张撕角票价签：慢慢挑 40s / 正常逛 30s / 限时抢 20s。
- 右侧：
  - 牛来“员工照”贴纸：深色照片、奶油相框、胶带、手写批注“本月销冠”；
  - 台词气泡：“我只拿当前最划算的那一个。”；
  - 主按钮“进店应战”；
  - 底部小字“没有登录，没有后端，只有一头很会算账的牛。”

### 4.2 游戏页

- 顶栏：品牌小章、第 N 单、累计、声音。
- 移动端 Boss 压缩成一条“店员动态”并带一句风凉话。
- 背包：牛皮纸袋造型，虚线袋口，物品以贴纸形式排列；容量刻度做成纸尺。
- 货架：物品卡像小包装 + 价签，显示“重 / 值”；已选卡盖“已装”章。
- 右侧（桌面）：Boss 照片、实时台词气泡、圆形计时器、交卷按钮。
- 计时器：环形进度 + 大数字；最后 1/3 时间转朱砂。
- 交卷按钮：“就这些，结账！”，空包时禁用并写“先装点东西”。
- Boss 风凉话触发：第一件、连续拿取、退回、超重、接近满袋、剩 10 秒、交卷。
- 玩家反馈：超重时禁止 + 抖动 + 一句“包：我真的会谢。”；接近满袋时容量尺变红。
- 拖拽保留，点击仍是主路径。交卷后 0.8 秒“数货中”遮罩，再进结算。

### 4.3 结算页

- 一张居中的结账单，底部锯齿，顶部胶带；抬头“贪心小卖部 · 结账单”，带单号/难度/用时。
- 主判定：
  - 赢：“这波，你赢了”；
  - 平：“打平，谁也没多得”；
  - 负：“老板多赚一口”。
- 评级圆章：S 神算 / A 稳赚 / B 小赚 / C 差点 / D 被拿捏。
- 三列票据行：你 / 牛来 / 最优解；数值、重量、物品小图标；最优列盖“标准答案”。
- 分数拆解：最优率 + 击败奖励 + 时间奖励 = 本单得分。
- 老板点评：Boss 头像 + 胜负台词 + 一句额外风凉话。
- 本局人设：由结果和操作统计选出（人形计算器 / 快手老贼 / 反复横跳王 / 闷声发财 / 五五开 / 差一块钱 / 硬塞选手 / 被拿捏了）。
- 老板套路：揭示 Ratio Greedy，用一句人话解释“单价 = 值 ÷ 重”。
- 贪心即最优的特殊局：明确写“这局，贪心真就是标准答案”。
- 操作：再来一单（主）、复制战绩、回店门口。
- 满配：额外“满配”章 + 纸屑。

### 4.4 操作统计

为“人设”和点评记录：

```ts
interface PlayStats {
  picks: number;       // 放入次数
  removals: number;    // 拿出次数
  rejections: number;  // 超重被拒次数
  items: number;       // 最终件数
}
```

只用于文案，不影响计分。

## 5. 文案系统

### 5.1 原则

- 主文案中文；英文只做票据注脚/编号。
- Boss 毒舌但不骂人，玩家输了也要有台阶。
- 教学信息用一句人话，不写公式墙。
- 同一事件准备 3–5 条，避免连续重复。

### 5.2 Boss 台词库（牛来）

| 场景 | 示例 |
|---|---|
| 开场 | “我只拿当前最划算的那一个。” |
| 首次拿取 | “眼光不错。可惜，不够贪。” |
| 连续拿取 | “拿，继续拿。包会替你算账。” |
| 退回 | “哦？反悔了？我也常反悔。” |
| 超重 | “塞不下就是塞不下，别硬塞。” |
| 接近满袋 | “满了满了，再塞要爆了。” |
| 最后 10 秒 | “手别抖，账会错。” |
| 交卷 | “行，开盲盒。” |
| 赢 | “贪心，从不回头看。” |
| 输 | “……这不对。让我再算一遍。” |
| 平 | “算你跟我一样贪。” |
| 满配 | “你把标准答案抄了？” |
| 贪心即最优 | “看见没，贪心有时候真是对的。” |

### 5.3 玩家“本局人设”

| 条件 | 人设 | 点评 |
|---|---|---|
| 满优 | 人形计算器 | 标准答案就写在货架上，你只是把它拿下来了。 |
| 赢且剩余时间 ≥ 40% | 快手老贼 | 手快，心更黑。老板还没拨完算盘。 |
| 赢且退回 ≥ 3 | 反复横跳王 | 拿进拿出，最后还真让你算对了。 |
| 赢 | 闷声发财 | 不声不响，把老板算进去了。 |
| 平 | 五五开 | 你和老板的算盘，今天同一个响。 |
| 输但最优率 ≥ 90% | 差一块钱 | 就差一点。老板笑得很轻。 |
| 输且超重尝试 ≥ 3 | 硬塞选手 | 包装不下，欲望装得下。 |
| 其余 | 被拿捏了 | 你盯着眼前，老板盯着你的包。 |

## 6. 声音规格

- `src/lib/audio.ts` 单例，懒创建 AudioContext。
- 主音量约 0.5；音乐循环音量约 0.05–0.08，不能盖住点击。
- 五声音阶，约 92 BPM，8 小节循环；只用合成器，不引用外部音频。
- 音效：tap / pick / remove / reject / tick / submit / win / lose / tie / perfect。
- 静音状态写入 `beat-greedy:sound`；刷新保持。
- 页面隐藏时暂停音乐，回来继续；首次用户手势解锁。
- 失败创建音频（浏览器限制）时静默降级。

## 7. 素材与 IP 边界

- 物品图标全部自绘 SVG，不使用第三方图标包或 emoji 作为主视觉。
- Boss 使用项目内已有的原创立绘，不新增官方 logo / 吉祥物 / 网络原图。
- 字体子集来自 OFL-1.1 的 Smiley Sans，按保留字体名要求重命名；随包附 OFL 文本和修改说明。
- 参考图仅内部研究，不进入构建产物。

## 8. 验收标准

- [ ] 首屏 3 秒内看懂“选货 → 装包 → 比老板算得更好”。
- [ ] 全站中文为主；英文只出现在票据注脚/编号。

- [ ] Boss 在至少 5 个事件上会说不同的话，且连续两局不重复同一句。
- [ ] 结算显示三列物品、分数拆解、老板点评、本局人设、套路揭示。
- [ ] 复制战绩可用，并包含链接。
- [ ] 声音默认开启、首次手势后播放；静音刷新后保持；页面隐藏暂停。
- [ ] `npm test`、`npm run lint`、`npm run build` 全绿；无 console error。
- [ ] OG 图、favicon、标题、描述都换成新视觉与中文。
