# BEAT GREEDY — Boss 考据与原创设计 Brief

> Last updated: 2026-10-20
> 用途：把网络梗转成可玩的 Boss 设定。**只做原创 homage，不直接使用官方 logo、官方吉祥物、平台二创原图或真人肖像。**
> 参考链接仅用于考据；游戏内立绘全部重新设计生成。

---

## 0. 使用边界

- 不打包、不二改、不描摹官方品牌资产：OpenAI knot、Google G / 四角星、X logo、Anthropic 字标、DeepSeek 鲸鱼 logo、美团袋鼠 logo 都不进入游戏。
- 不直接使用现有二创角色：例如 GPT 的 Astra 龙娘、DeepSeek 的溟月/鲸鱼娘/D老师、xAI 的 Ani。这些都有明确的作者或版权归属。
- 真人梗（梁子/梁圣、Tibo）只取“角色气质 + 梗”，不做真人肖像；公开版本用虚构代号和原创形象。
- 对外显示名优先使用梗化别名；中文梗名保留在角色设定/台词中，不把品牌名当做游戏资产。
- 画风统一：原创扁平静态立绘，粗描边、少量网点、夸张表情、头身比约 1:2。Boss 卡内使用方形/半身像，暗底 + 专属强调色。

## 1. 第一幕：LOCAL OPTIMUM（抽象梗阵容）

### 01. 奶蛙 / MILK FROG

**梗考据**

- 奶蛙不是独立原创 IP，而是 2025 年末–2026 年初从 **奶龙（Nailong）** 的“大笑奶龙”变体里长出来的互联网变体：黄色梨形身体、肿胀的大头、爆出的绿白色眼睛、夸张大笑。网友把“像青蛙”的版本单独命名为奶蛙，2026 年春季成为独立梗。
- 气质：阴间可爱、欠揍、魔性，没有正经台词，只有卡痰笑声和“咕咕嘎嘎”。
- 参考：[Bilibili 来源考据](https://www.bilibili.com/video/BV1Z1d5BVEGs/) · [Gcores 梗分析](https://www.gcores.com/articles/217077) · [奶蛙 fan wiki](https://neta.art/app/milk-frog-wiki)

**原创设计（按 2026-10-20 参考图修正）**

- 柠檬黄、上窄下宽的梨形/豆形身体，巨大奶白肚皮，小头与身体几乎无脖子，绿色凸眼、黑点瞳孔、细小黑短肢。
- 两个核心表情：**平静呆滞**（用户参考图，适合失败/结算）与**超大张嘴爆笑**（传播最广的梗图版本，适合 Boss 立绘）。
- 道具只保留一瓶牛奶；奶茶杯王冠不是参考图元素，已从设计中移除。
- 专属色：`#F2D64B` 柠檬黄 + `#F6F0D8` 奶白 + `#8CB63F` 蛙绿。
- 游戏内策略：**VALUE GREEDY** — 永远拿面值最大的那个。
- 台词：开场「最贵的那口，先归我。」胜利「咕咕嘎嘎。你还在算？」失败「嗝……刚才那口不算。」
- 避免：奶龙原版造型、任何官方周边图、AI 奶龙二创原图。

### 02. 黄鼠 / YELLOW RUSH

**梗考据**

- 美团官方吉祥物其实是黄色袋鼠，不是老鼠；因为 2021 年的圆脸、小圆耳、呆萌笑容改版，被网友叫成“黄色老鼠/呆鼠”。2026 年“你的胆子真是肥嘟嘟的”梗又与它绑定。
- 视觉：美团黄、圆润梨形身体、大耳朵、豆豆眼、简单大笑容、短手短脚、外卖箱。
- 参考：[Bilibili 相关梗](https://www.bilibili.com/video/BV1vPbq6TEUx/) · [UIED 解析](https://www.uied.cn/posts/921772) · [搜狐相关报道](https://www.sohu.com/a/1067668042_121119389)

**原创设计（按 2026-10-20 参考图修正）**

- 实际梗图是**黄色袋鼠**：长立耳、大棕鼻、棕色大眼、吐舌笑、比耶；“你的胆子真是肥嘟嘟的”坐姿毛绒形象进一步强化了圆润感。
- 游戏立绘保留这些识别点，并加入原创元素：手绘闪电外卖箱、秒表、前倾冲刺姿态。
- 专属色：`#FFD400` 外卖黄 + `#6B3F1D` 暖棕 + `#FF6B35` 橙红 + `#1C1C16` 墨黑。
- 游戏内策略：**WEIGHT GREEDY** — 最轻的先拿，保持速度。
- 台词：开场「轻的，先跑。」胜利「超时了，宝贝。」失败「你……你居然比我先到。」
- 避免：美团 logo、官方吉祥物原图、品牌字样。

### 03. 牛来 / BULL RUSH

**梗考据**

- 《牛来》是 2026-08-05 上映的国产粗糙 3D 动画电影，由两人小团队制作，以“烂到好笑”的方式出圈；主角是橙黄色小牛，直立行走、超大脑袋、圆眼、僵直手臂、死鱼眼，低多边形穿模感。
- 名场面是小牛摔倒、四脚朝天；台词梗「妈妈，牛来！」；“牛来”谐音牛市，成为牛马/股民情绪出口。
- 参考：[Bilibili 梗百科](https://www.bilibili.com/video/BV1Lqby6oE7i/) · [Baidu Baike（可能 403）](https://baike.baidu.com/item/牛来/59676341) · [Wikipedia](https://zh.wikipedia.org/zh-cn/牛来)

**原创设计（按 2026-10-20 参考图修正）**

- 原片识别点：橙黄色、超大脑袋、白色口鼻、短角、棕色大眼、直立站姿、短而僵的手臂，低多边形面片感。
- 游戏内加一件不合身的白衬衫和短线领带，一只蹄子夹计算器；这是把“牛马”梗和 Ratio Greedy 绑定的原创设计，不复制电影海报构图或字体。
- 表情保留“死鱼眼 + 微微下垂”的呆滞感；失败时可做四脚朝天表情包。
- 专属色：`#FF8B3D` 橙 + `#F2EBDD` 米白 + `#1A1A16` 墨黑。
- 游戏内策略：**RATIO GREEDY** — 按 value / weight 排序，装不下就跳过。
- 台词：开场「我只拿当前最划算的那一个。」胜利「贪心，从不回头看。」失败「……这不对。让我再算一遍。」
- 避免：电影原始截图/海报、真实的电影字体设计。

### 04. 梁子 / THE ENGINEER

**梗考据**

- 梁子、梁圣不是固定角色，而是 DeepSeek 创始人梁文锋的社区评价梗：从“小难梁 → 牢梁 → 梁子 → 梁圣 → 梁祖”的“滑动变祖器”。发布强势、便宜的新模型时升格为“梁圣”，涨价、延迟、宕机时降格为“梁子”。
- 社区视觉主要是蓝西装真人照片 + Gigachad/圣光 PS，不是统一的二次元角色。
- 参考：[Bilibili 相关梗](https://www.bilibili.com/video/BV1Pxum6PEws/) · [虎嗅时间线](https://www.huxiu.com/article/4881400.html) · [滑动变祖器工具](https://github.com/cholf5/liang-slider)

**原创设计**

- **不画真人**。虚构的蓝发工程师：深蓝连帽衫、黑眼圈、冷静又疲惫的表情；周围悬浮简化的调试窗口、坐标系和 token 计数条。没有 DeepSeek logo。
- 梁圣形态是同一角色的“升格”：白蓝长袍、几何光环、公式环，表情平静；保留疲惫感，不要做成宗教神像。
- 专属色：`#1E4FFF` 深蓝 + `#E8EEFF` 冷白 + `#7FB2FF` 冰蓝。
- 游戏内策略：**RATIO + ONE SWAP** — 先 ratio 贪心，再做一次最佳单件替换。
- 台词：开场「贪心之后，我会复盘。」胜利「你没有复盘。」失败「这个解……比我的更优。」平局「工程上可以接受。」
- 避免：真人面部特征、梁文锋照片、DeepSeek 品牌字标与鲸鱼 logo。

## 2. 第二幕：AI ARENA（拟人二创阵容）

> 现状：中文互联网没有官方“AI 娘”正典；主流形象来自 B 站手书、AI 图、小红书/微博表情包。以下全部是**原创角色**，只继承用户对品牌的气质印象，不复刻已有二创。

### 05. THE PLANNER（GPT 拟人）

- 社区印象：白发龙娘/女仆，绿白蓝配色，OpenAI 结作为光环；“过度听话的赛博舔狗”和“企业级礼貌”是常见笑点。
- 原创设计：白发、淡绿发梢、龙角与短翼的合成人，钴蓝/白制服，胸前挂编号牌；光环是一圈**空白几何纸片**（不是 OpenAI 结）。手托悬浮任务卡，微笑得体但眼神过度平静。
- 专属色：`#F2F5FF` 白 + `#2557FF` 钴蓝 + `#7AF0C3` 薄荷绿。
- 参考板验证：白发/浅绿发 + 龙角 + 蓝白制服是稳定组合；纸片光环和编号牌是我们额外加的“企业级”记忆点。
- 策略：同时跑 ratio 和 value 两种贪心，取结果更好的一个（“多步规划”的伪实现）。
- 台词：「先澄清目标，再开始选择。」/「我理解你的意图，但这不是最优方案。」
- 避免：OpenAI knot、官方字标、Astra 龙娘设计。

### 06. THE JUDGE（Claude 拟人）

- 社区印象：橙色长发、珊瑚/奶油/黑礼服、旧书与宪法；守序善良的圣骑士/风纪委员，礼貌、啰嗦、拒绝一切。
- 原创设计：橙发、疲惫又挑剔的眼睛，奶油色长外套 + 炭黑衣领，珊瑚色腰带；抱一本没有字的大法典，另一只手拿小木槌。表情是“我理解你，但我建议你别这么做”。
- 专属色：`#F6D6BD` 奶油 + `#E76F51` 珊瑚 + `#25231F` 炭黑。
- 参考板验证：橙发 + 奶油长外套 + 深色高领的组合最稳定；书和木槌负责区分“判断者”而不是普通学者。
- 策略：保守 ratio — 前期只接受重量不超过剩余容量 1/3 的物品，最后才放宽。
- 台词：「我理解你的意图，但我建议更稳妥的方案。」/「先澄清目标，再开始选择。」
- 避免：Anthropic 字标、官方品牌图、现有 Claude 二创原图。

### 07. TWIN SPARK（Gemini 拟人）

- 社区印象：蓝紫渐变长发、星形发饰/瞳孔、白色偶像外套；猫娘/病娇/夸夸娘等版本都流行。
- 原创设计：蓝紫双色双马尾，两颗环绕她的球形“星火”，没有 Google G；衣服是白/蓝渐变，领口有一枚**六角纸星**而不是官方四角星。表情明亮、过度热情，像一个会同时给出四个答案的主持人。
- 专属色：`#6F7BFF` 蓝紫 + `#C36BFF` 紫 + `#FFD45C` 金。
- 参考板验证：蓝紫双马尾 + 星星发饰 + 偶像外套是社区最稳定的识别组合；我们用六角纸星和两个球形星火替代官方四角星与 G 标。
- 策略：多策略合议 — value / ratio / weight 三种贪心结果取最优。
- 台词：「我不只看文字，我看整个世界。」/「输入越多，我越强。」
- 避免：Google G、官方 sparkle、现有 Gemini 猫娘/病娇设计原图。

### 08. THE REBEL（Grok 拟人）

- 社区印象：金发双马尾、哥特黑裙、蝙蝠翅膀/新月、巨大斧头；混沌、嘴臭、叛逆。xAI 官方 Ani 是受版权保护的官方角色，不能直接使用。
- 原创设计：短发凌乱的金发、单边蝙蝠翼耳饰、黑红不对称夹克、破洞丝袜；武器换成一把喷着“?”的巨型扳手/撬棍，不讲武德地笑。不要 X logo，不要 Misa 式复刻。
- 专属色：`#141414` 黑 + `#C8102E` 血红 + `#FFE66D` 金。
- 参考板验证：金发 + 黑色哥特裙 + 蝙蝠元素是社区对 Grok 的主要视觉投射；我们改成乱短发、不对称皮夹克和巨型撬棍，避开 Ani 的完整造型。
- 策略：逆向 ratio — 先拿“最不划算”的，制造混乱；高方差。
- 台词：「你按规则玩？真可爱。」/「我不按常规出牌。」
- 避免：Ani、X logo、官方 Grok 品牌图。

### 09. THE SAINT（DeepSeek 梁圣形态）

- 社区印象：梁文锋的“梁圣”升格梗；圣光、光环、Gigachad 体型，是对模型性价比的夸张膜拜。
- 原创设计：工程师的升格形态，蓝白长袍、几何光环、周围悬浮着没有文字的公式与 token 条；表情平静、略带疲惫，像一个刚熬完夜的圣人。
- 专属色：`#DAE6FF` 冷白 + `#245BFF` 蓝 + `#9A7BFF` 紫。
- 参考板验证：DeepSeek 二创的主流确实是“蓝发鲸鱼女仆”（白围裙、鲸尾），但那属于别人的角色设计；我们刻意走“蓝发工程师 → 冰蓝圣者”的原创路线，用几何光环、公式卡和 token 条表达“升格”，不画鲸鱼。
- 策略：ratio + 多轮单件替换的局部搜索，几乎最优；Boss Rush 的隐藏 Boss。
- 台词：「贪心，不过是凡人的捷径。」/「你距离最优，只差一次顿悟。」
- 避免：真人肖像、DeepSeek logo、宗教造像式的直接挪用。

### 10. THE RESETTER（Tibo 梗，可选秘密 Boss）

- 社区印象：Tibo = Thibault Sottiaux，OpenAI Codex 产品负责人；因频繁重置额度被中文开发者称为“赛博义父/重置之神”，梗图元素是圣光、红色 RESET 按钮、额度条、祈祷手势。没有成熟的拟人正典。
- 原创设计：疲惫的天使型产品经理，头戴耳机，光环是加载中的圆环，抱一块巨大的红色 RESET 按钮；白衬衫、松垮领带、黑眼圈。不是真人肖像。
- 专属色：`#F4F4F4` 白 + `#FF3B30` 红 + `#3C3C43` 炭灰。
- 参考板验证：Tibo 梗没有成熟拟人正典，主要是“圣光 + RESET 按钮 + 额度条 + 祈祷手势”的拼贴；因此我们只借用“疲惫天使 PM + 加载中光环 + 红色重置按钮”，完全是原创角色。
- 机制钩子（暂不实现）：每局一次“reset”，可重置倒计时或刷新一件物品；作为彩蛋 Boss 而不是正常贪心 Boss。
- 台词：「额度，我说了算。」/「重置一下，刚才不算。」
- 避免：真人照片、OpenAI logo、把现实公司福利做成付费/抽卡机制。

## 3. 策略映射

| Boss | Knapsack | Scheduling（后续） | TSP（后续） |
|---|---|---|---|
| 奶蛙 | 最大价值优先 | 最高奖励优先 | 最贵边优先 |

| 梁子 | ratio + 单次 swap | 单次交换改进 | 2-opt 一步 |

| Judge | 保守 ratio | 先做安全任务 | 先走安全边 |
| Twin Spark | 三策略取优 | 三套排序取优 | 三种启发式取优 |
| Rebel | 逆向 ratio | 最不紧急优先 | 最远城市优先 |
| Saint | 多轮局部搜索 | 多轮交换 | 2-opt |
| Resetter | 特殊局 | 特殊局 | 特殊局 |

## 4. 统一美术提示词（给 ImageGen / 美术）

**风格基线**

> Flat 2D screen-printed sticker illustration, bold black ink outlines, limited palette, subtle halftone shading, exaggerated meme expression, chibi proportions with a large head and compact body, centered half-body portrait, dark charcoal-olive background, crisp acid-colored rim light, original character design, no text, no letters, no logos, no watermarks.

**生成原则**

- 1024×1024，一张图只放一个 Boss，留出顶部和底部安全区。
- 造型优先“远看一眼能认”，不要堆细节；每个角色最多 2 个主道具。
- 不使用品牌色以外再叠加品牌标识；不出现任何字标。
- Boss 立绘与 UI 的暗墨底、酸性黄强调色统一；Boss 自身用专属辅色区分。
- 真人梗角色一律用虚构造型，不做面部相似。
